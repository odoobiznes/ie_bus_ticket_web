# Modern Bus Booking System

Сучасна система бронювання автобусних квитків для Odoo 19.0

## Опис

Повнофункціональна система бронювання автобусних квитків з:
- Сучасним responsive дизайном
- 3-етапним процесом бронювання
- Інтеграцією з платіжною системою Odoo
- Генерацією QR-кодів для квитків
- Email підтвердженнями та рахунками

## Встановлення

### Передумови
- Odoo 19.0
- Модуль `ie_bus_ticket_admin` (базова система управління автобусами)
- Модулі `website`, `website_sale`, `account`, `sale_management`

### Кроки встановлення

1. **Копіювання модуля**
   ```bash
   cp -r ie_bus_ticket_web /path/to/odoo/addons/
   ```

2. **Оновлення списку додатків**
   - Перейдіть в Odoo: Налаштування → Додатки
   - Натисніть "Оновити список додатків"

3. **Встановлення модуля**
   - Знайдіть "Modern Bus Booking"
   - Натисніть "Встановити"

### Конфігурація

1. **Налаштування точок посадки/висадки**
   - Перейдіть в меню "Автобуси" → "Точки"
   - Додайте необхідні зупинки

2. **Створення маршрутів**
   - Перейдіть в "Автобуси" → "Маршрути"
   - Налаштуйте маршрути з ціноутворенням

3. **Налаштування автобусів**
   - Додайте автобуси в "Автобуси" → "Автобуси"
   - Налаштуйте схеми сидінь

## Використання

Система доступна за адресою: `/bus-booking`

### Функціонал для користувачів:
- Пошук маршрутів
- Вибір місць
- Бронювання та оплата
- Отримання електронних квитків

### Функціонал для адміністраторів:
- Перегляд статистики продажів
- Управління неоплаченими бронюваннями
- Інформація про пасажирів

## Технічні деталі

### Маршрути
- `/bus-booking` - головна сторінка пошуку
- `/bus-booking/search-routes` - пошук маршрутів
- `/bus-booking/book` - вибір місць
- `/bus-booking/confirmation/<id>` - підтвердження бронювання
- `/bus-booking/pay` - обробка платежів

### API ендпоінти
- `/bus-booking/reserve` - резервація місць (JSON-RPC)
- `/bus-booking/get-passenger-info` - інформація про пасажира (JSON-RPC)
- `/bus-booking/get-unpaid-reservations` - неоплачені бронювання (JSON-RPC)
