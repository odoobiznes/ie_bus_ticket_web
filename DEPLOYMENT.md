# Інструкція з розгортання на devops.it-enterprise.cz

## Підготовка до розгортання

### 1. Перевірка залежностей

Переконайтеся, що на сервері встановлені всі необхідні модулі:

```bash
# Базові модулі Odoo (зазвичай вже встановлені)
- website
- website_sale
- account
- sale_management

# Спеціальний модуль (потрібно встановити окремо)
- ie_bus_ticket_admin
```

### 2. Завантаження модуля на сервер

```bash
# Підключення до сервера
ssh user@devops.it-enterprise.cz

# Перехід до директорії додатків Odoo
cd /opt/odoo/addons/

# Завантаження модуля (один з варіантів):

# Варіант 1: Через Git (рекомендовано)
git clone <repository_url> ie_bus_ticket_web

# Варіант 2: Через SCP
scp -r /local/path/ie_bus_ticket_web user@devops.it-enterprise.cz:/opt/odoo/addons/

# Варіант 3: Через rsync
rsync -avz ie_bus_ticket_web/ user@devops.it-enterprise.cz:/opt/odoo/addons/ie_bus_ticket_web/
```

### 3. Налаштування прав доступу

```bash
# Встановлення правильного власника
sudo chown -R odoo:odoo /opt/odoo/addons/ie_bus_ticket_web

# Встановлення прав доступу
sudo chmod -R 755 /opt/odoo/addons/ie_bus_ticket_web
```

### 4. Перезапуск Odoo

```bash
# Перезапуск сервісу Odoo
sudo systemctl restart odoo

# Або якщо Odoo запущено в Docker
docker restart odoo_container
```

## Встановлення через веб-інтерфейс

### 1. Оновлення списку додатків

1. Увійдіть в Odoo як адміністратор
2. Перейдіть: **Налаштування** → **Додатки**
3. Натисніть **"Оновити список додатків"**
4. Підтвердіть оновлення

### 2. Встановлення модуля

1. В пошуку додатків введіть: `Modern Bus Booking`
2. Знайдіть модуль в списку
3. Натисніть **"Встановити"**
4. Дочекайтеся завершення встановлення

### 3. Перевірка встановлення

Перейдіть за адресою: `https://devops.it-enterprise.cz/bus-booking`

Ви повинні побачити головну сторінку системи бронювання.

## Початкова конфігурація

### 1. Налаштування точок посадки/висадки

```
Меню: Автобуси → Точки
```

Додайте основні зупинки:
- Назва точки
- Адреса
- Координати (опціонально)

### 2. Створення маршрутів

```
Меню: Автобуси → Маршрути
```

Для кожного маршруту налаштуйте:
- Початкову та кінцеву точки
- Час відправлення та прибуття
- Дні тижня роботи
- Ціноутворення (спеціальні ціни)

### 3. Додавання автобусів

```
Меню: Автобуси → Автобуси
```

Налаштуйте:
- Модель автобуса
- Кількість місць
- Схему розташування сидінь

### 4. Налаштування платежів

```
Меню: Веб-сайт → Конфігурація → Платіжні системи
```

Активуйте необхідні платіжні системи:
- Банківські картки
- PayPal
- Інші локальні системи

## Тестування

### 1. Функціональне тестування

1. **Пошук маршрутів**
   - Перейдіть на `/bus-booking`
   - Виберіть точки відправлення та призначення
   - Виберіть дату
   - Натисніть "Знайти рейси"

2. **Бронювання**
   - Виберіть маршрут
   - Оберіть місця
   - Заповніть дані пасажира
   - Підтвердіть бронювання

3. **Оплата**
   - Перейдіть до оплати
   - Протестуйте платіжну систему
   - Перевірте отримання підтвердження

### 2. Адміністративне тестування

1. **Статистика** (для адміністраторів)
   - Перевірте відображення статистики на головній сторінці
   - Переглянте неоплачені бронювання

2. **Управління бронюваннями**
   - Перевірте можливість перегляду інформації про пасажирів
   - Протестуйте функції адміністрування

## Моніторинг та підтримка

### 1. Логи

Перевіряйте логи Odoo на наявність помилок:

```bash
# Перегляд логів
sudo tail -f /var/log/odoo/odoo.log

# Fильтрace по modulu
sudo grep "ie_bus_ticket_web" /var/log/odoo/odoo.log
```

### 2. Резервне копіювання

Регулярно створюйте резервні копії:

```bash
# Резервна копія бази даних
pg_dump odoo_database > backup_$(date +%Y%m%d).sql

# Резервна копія файлів модуля
tar -czf ie_bus_ticket_web_backup_$(date +%Y%m%d).tar.gz /opt/odoo/addons/ie_bus_ticket_web/
```

### 3. Оновлення

При оновленні модуля:

1. Створіть резервну копію
2. Замініть файли модуля
3. Перезапустіть Odoo
4. Оновіть модуль через веб-інтерфейс

## Усунення проблем

### Типові проблеми:

1. **Модуль не відображається в списку**
   - Перевірте права доступу до файлів
   - Оновіть список додатків
   - Перевірте логи на наявність помилок

2. **Помилки при встановленні**
   - Перевірте наявність залежностей
   - Перевірте синтаксис Python файлів
   - Переглянте логи Odoo

3. **CSS не завантажується**
   - Очистіть кеш браузера
   - Перевірте налаштування assets в `__manifest__.py`
   - Перезапустіть Odoo
